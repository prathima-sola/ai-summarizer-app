# Two-minute Briefly demo

## 0:00 to 0:20

Open `/demo`. Explain that the sample runs without an account, file upload, or model call. Point to the capability proof and the two-page source.

## 0:20 to 0:50

Open a citation in the brief. Show how the source viewer moves to the cited page. Explain that the server checks page numbers and quotations before saving generated output.

## 0:50 to 1:15

Open **Ask the document**. Choose each sample question and open its supporting page. Explain that production answers retrieve only chunks owned by the signed-in user.

## 1:15 to 1:35

Open **evidence**. Select a page-two quotation. Show the private-source boundary described in the sample and connect it to revocable result sharing.

## 1:35 to 2:00

Open the private workspace in a second tab. Show upload states, OCR coverage, saved history, comparison, the quality dashboard, and sharing. Close with the production lifecycle test, readiness probe, and cleanup guarantees.

## Recording checklist

- Record at 1440 by 900 with browser zoom at 100%.
- Hide bookmarks, personal tabs, environment files, and developer credentials.
- Use the committed sample first so the recording never depends on a live AI call.
- Keep the final clip under two minutes and add captions.
- End on the live URL and GitHub repository.
